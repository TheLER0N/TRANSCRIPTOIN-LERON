Шаг 1: Локальный бэкап текущего состояния
Файлы:
- (новый файл) — создать архив или папку-копию текущей директории `LERON-GUI-main` для страховки от потери несохранённых локальных правок и черновиков.
Критерий готовности: резервная копия создана, можно безопасно перезаписывать локальные файлы.

Шаг 2: Настройка Git для Windows 11 (защита кодировки и CRLF)
Файлы:
- (новый файл) — применить локальные настройки git в папке проекта: `git config core.autocrlf true` (сохранение CRLF для `.bat`), `git config core.quotepath false` (корректный вывод кириллицы), `git config i18n.logOutputEncoding utf-8`.
Критерий готовности: Git сконфигурирован так, чтобы при перезаписи файлов не ломать окончания строк в скриптах и не превращать кириллицу в escape-последовательности.

Шаг 3: Загрузка истории и жёсткий откат (Hard Reset)
Файлы:
- (новый файл) — выполнить `git fetch origin` для загрузки всех коммитов с GitHub.
- (новый файл) — выполнить `git reset --hard origin/main` (или `git reset --hard <SHA-1_хэш>`, если рабочая версия не является последним коммитом в main) для побайтового выравнивания локальных файлов с удалёнными.
Критерий готовности: `git status` показывает "working tree clean", локальные файлы полностью соответствуют версии с GitHub без вмешательства текстовых редакторов.

Шаг 4: Проверка целостности `.bat` и запуск
Файлы:
- push-to-github.bat — проверить, что `chcp 65001` и кириллица в `echo` читаются в терминале Windows 11 без искажений.
- start.bat — запустить для проверки, что проект стартует, а `dotnet build` не падает из-за BOM или сломанных путей.
Критерий готовности: `.bat` файлы выполняются, в консоли нет "кракозябр", GUI успешно запускается.
