# PROJECT_INFO.md

Назначение: объяснить ИИ, что такое LERON-GUI и где искать ключевые части.

LERON-GUI — локальное WPF-приложение для работы с ИИ-агентом через браузерный Qwen/WebView2. Оно ведёт чат, выполняет файловые операции, собирает блок-схемы, хранит память проекта и запускает GUI-тесты.

## Назначение

1. Дать пользователю один интерфейс для чата с ИИ по проекту.
2. Разрешить агенту читать и писать файлы внутри проекта.
3. Собирать и редактировать блок-схемы без ошибок GUI.
4. Показывать статусы, карточки подтверждения и результаты тестов.
5. Хранить рабочие данные в предсказуемых путях.

## Ключевые пути

1. `program/main/chat` — чат, карточки, режимы ввода, ответы агента.
2. `program/main/browser` — WebView2, мост к Qwen, отправка промтов, приём потока.
3. `.leron` — схемы, память, индексы, локальные артефакты.
4. `logs` — отчёты GUI-тестов и диагностика.
5. `config.json` — проекты, роли, настройки подтверждений.

## Текущая цель

Привести GUI к релизу 1: один ввод, рабочие инструменты, целые блок-схемы, зелёные тесты.
