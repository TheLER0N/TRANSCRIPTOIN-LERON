# PROJECT_INFO.md
Назначение: объяснить ИИ, что такое LERON-AUDIO и где искать ключевые части.

LERON-AUDIO — локальное WPF-приложение для PTT-транскрибации через Whisper.cpp: зажал глобальный хоткей — сказал фразу — отпустил — текст распознан локально и положен в буфер обмена либо вставлен в активное окно. Без облака, без чата, без хранения истории.

## Назначение
1. Push-to-talk диктовка через глобальный хоткей (по умолчанию F4) или большую кнопку в окне.
2. Локальное распознавание речи: Whisper.Net in-process (основной путь) и whisper-cli.exe (резервный), модель ggml-large-v3-turbo.bin.
3. Выдача результата: копирование в буфер обмена всегда; опциональная авто-вставка Ctrl+V в активное окно.
4. Настройки без перезапуска: хоткей, микрофон, авто-вставка, путь к модели, запуск свёрнутым.
5. Контроль качества входа: VU-метр уровня микрофона и защита от пустой записи (WAV без данных не отправляется на распознавание).

## Ключевые пути
1. `code/Services` — захват аудио (`NAudioCaptureService`, `TempWavWriter`), STT (`WhisperNetService`, `WhisperCliService`), хоткей (`NHotkeyService`), буфер и авто-вставка (`ClipboardService`), настройки (`SettingsService`), поиск модели и CLI (`ModelLocator`).
2. `code/ViewModels` — `MainViewModel` (оркестрация PTT: запись → транскрипт → буфер/вставка), `SettingsViewModel`.
3. `code/MainWindow.xaml` — главное окно: VU-метр, PTT-кнопка, поле транскрипта, статус, кнопки.
4. `code/Windows/SettingsWindow.xaml` — настройки: вкладки «Горячие клавиши», «Микрофон», «Вставка», «Модель», «Запуск».
5. `settings.json` — пользовательские настройки рядом с .exe (в git не коммитится).
6. `ggml-large-v3-turbo.bin` — модель Whisper в корне проекта (в git не коммитится, скачивается `download-model.bat`).
7. `build/` — whisper-cli.exe и DLL whisper.cpp (в git не коммитится, скачивается `download-whisper-cli.bat`).
8. `start.bat`, `download-model.bat`, `download-whisper-cli.bat`, `release-to-github.bat` — запуск, подготовка окружения и релиз.

## Текущая цель
Довести LERON-AUDIO до релиза 1. Шаги 1–7 плана выполнены и подтверждены скриншотом: сборка проходит, PTT-диктовка работает, текст попадает в буфер, настройки открываются и сохраняются. Активен Шаг 8 (документация), далее Шаг 9 (иконка, ручной сценарий, релизная сборка).
