# VISION.md
Назначение: задать целевое состояние LERON-AUDIO и границы обновлений.

## 1. Итоговый продукт
LERON-AUDIO к релизу 1 — стабильная локальная PTT-диктовка: один хоткей → запись → транскрипт → буфер обмена / авто-вставка. Чистый тёмный UI, предсказуемые статусы, ни один байт аудио и текста не покидает машину.

## 2. Целевые способности
1. Один глобальный хоткей (по умолчанию F4, настраиваемый) запускает запись по нажатию и останавливает по отпусканию.
2. Локальное распознавание через Whisper.cpp с моделью ggml-large-v3-turbo.bin, язык определяется автоматически.
3. Текст после распознавания всегда копируется в буфер обмена; при включённой авто-вставке эмулируется Ctrl+V в активное окно (задержка 150 мс на фокус).
4. VU-метр в реальном времени показывает уровень микрофона; пустая и слишком короткая запись не отправляется на распознавание.
5. Настройки (хоткей, микрофон, авто-вставка, путь к модели, запуск свёрнутым) сохраняются в `settings.json` и применяются без перезапуска.

## 3. Принципы
1. Сначала работоспособность, потом расширение функций.
2. Один путь от голоса до текста: хоткей → захват 16 кГц моно 16 бит → временный WAV → Whisper → буфер/вставка.
3. Всё локально: никаких облачных STT и внешних API.
4. Ошибка подсистемы (микрофон, модель, CLI, хоткей) не роняет приложение — пользователь видит понятный статус в окне.
5. Тяжёлые артефакты (модель, whisper-cli.exe, DLL) не хранятся в git — скачиваются скриптами подготовки.

## 4. Границы
1. История диктовок не хранится: в окне виден только последний транскрипт.
2. Авто-вставка никогда не шлёт Ctrl+V в собственное окно LERON-AUDIO.
3. Приложение не перехватывает чужие глобальные хоткеи и не мешает системному вводу текста.
4. `settings.json` и `temp/` — локальные данные, в репозиторий не попадают.
5. Поле транскрипта только для чтения: приложение не является редактором текста.

## 5. Антицели
1. Не облачный STT и никакие внешние API распознавания.
2. Не чат, не диалог с ИИ, не агентные инструменты.
3. Не хранение истории транскриптов и не база знаний.
4. Не редактор текста и не обработка документов.
5. Не профили пользователей и не синхронизация между машинами.

## 6. Критерии релиза 1
1. `dotnet build` и `start.bat` проходят без ошибок.
2. Ручной сценарий «зажать F4 → сказать фразу → отпустить → текст в буфере → Ctrl+V в Блокноте» проходит 3 раза подряд.
3. Авто-вставка работает в Блокноте и Telegram при включённой настройке и выключена корректно при снятой галке.
4. Настройки сохраняются и применяются без перезапуска приложения.
5. Релизная сборка стартует на чистой Windows 11 x64 при наличии .NET 8, скачанной модели и whisper-cli.
