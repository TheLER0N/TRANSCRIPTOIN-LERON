# VISION.md

Назначение: задать целевое состояние LERON-GUI и границы обновлений.

## 1. Итоговый продукт

LERON-GUI к релизу 1 — стабильное локальное приложение: чат, агент, файлы, браузер, блок-схемы и тесты работают предсказуемо, визуально чисто, без технических ошибок.

## 2. Целевые способности

1. Одно главное поле ввода с режимами: `Проект`, `Схема`, `Без контекста`.
2. Агент читает файлы внутри проекта автоматически и продолжает работу без лишней карточки.
3. Блок-схемы создаются ИИ и редактируются пользователем без ошибок валидации и GUI.
4. Недоступная функция прекращает шаг с явным сообщением и списком доступных инструментов.
5. Полный GUI-тест возвращает читаемый `ВЕРДИКТ: PASS` или точную причину `FAIL`.

## 3. Принципы

1. Сначала работоспособность, потом расширение функций.
2. Один путь от ввода к ответу: ввод → агент → инструмент → карточка/ответ.
3. Контекст схемы передаётся только при явном прикреплении схемы к чату.
4. Опасные действия и доступ вне проекта требуют подтверждения.
5. Ошибка одной подсистемы не роняет всё приложение.

## 4. Границы блок-схем

1. Схема не заменяет память проекта.
2. Схема не заменяет файловый индекс.
3. Одна битая схема не блокирует всю библиотеку.
4. Несохранённая схема не теряется тихо.

## 5. Антицели

1. Не создавать второе рабочее поле отправки промта в разделе схемы.
2. Не прикреплять открытую схему к чату автоматически.
3. Не строить схему всего проекта автоматически при открытии.
4. Не смешивать чат схемы с чатом проекта без явного режима.
5. Не удалять старые схемы без миграции.

## 6. Формула ролей

1. Память хранит знания о проекте.
2. Файловый индекс помогает находить файлы.
3. Чат решает задачи.
4. Блок-схема объясняет конкретный процесс или объект.
5. Тесты подтверждают, что GUI работает.

## 7. Критерии релиза 1

1. Сборка проходит без ошибок.
2. Полный GUI-тест заканчивается `ВЕРДИКТ: PASS`.
3. Отправка промта работает в трёх режимах без дублей.
4. Чтение файлов внутри проекта выполняется автоматически.
5. Создание и редактирование схемы сохраняют валидные узлы и связи.
