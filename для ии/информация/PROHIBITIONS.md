# PROHIBITIONS.md

Назначение: жёсткие запреты на изменения и правила формата работы ИИ.

## Манифест файлов

Разрешённые постоянные файлы документации:

1. `PROJECT_INFO.md`
2. `VISION.md`
3. `TASK.md`
4. `PROHIBITIONS.md`

## Запреты на файлы

1. Не создавать новые `.md` и `.txt` файлы без прямой команды пользователя.
2. Не удалять, не переименовывать и не заменять 4 файла манифеста без прямой команды.
3. Редактировать только существующие файлы.
4. Не выдавать диффы вместо полного содержимого изменённого файла.
5. Не править файл больше 500 строк целиком: сначала разбить на части, затем править части.

## Запреты на поведение GUI

1. Не добавлять второе поле отправки промта в разделе схемы.
2. Не прикреплять открытую схему к чату автоматически.
3. Не выполнять доступ вне проекта без явного пути и подтверждения.
4. Не выполнять опасные команды без подтверждения, кроме явного режима auto/yolo.
5. Не скрывать ошибку недоступной функции: вернуть сообщение, список доступных инструментов и альтернативу или `finish`.

## Протокол ответа

1. `Размышление` — короткий разбор до действий.
2. `Заметки к задаче [ЗАМОРОЖЕННЫЙ БЛОК]` — первый ответ полный; далее «Заметки: отклонений нет.»; полная ревизия только по команде.
3. `Файлы` — полное содержимое каждого изменённого файла.
4. Ответы на уточняющие вопросы — формат теста с вариантами.
5. Запрещены вступления, повторы и заключительные любезности.
