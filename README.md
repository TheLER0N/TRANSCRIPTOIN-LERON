# LERON-AUDIO

Локальная PTT-диктовка (Push-To-Talk) для Windows на базе Whisper.cpp.

## Принцип работы
1. Зажимаешь глобальный хоткей (по умолчанию `F4`).
2. Говоришь фразу.
3. Отпускаешь — аудио распознаётся локальной нейросетью.
4. Текст копируется в буфер и автоматически вставляется (`Ctrl+V`) в активное окно.

## Ключевые возможности
- **Приватность**: аудио и текст обрабатываются строго на устройстве.
- **Скорость**: нативные рантаймы `whisper.cpp` (CPU, Vulkan, CUDA).
- **Code-switching**: встроенный словарь технических терминов предотвращает транслитерацию английских слов в русской речи.
- **DSP**: нормализация громкости и шумоподавление перед распознаванием.
- **История**: локальное хранение сессий с таймкодами.

## Установка
1. Скачай `.zip` из раздела Releases.
2. Распакуй и запусти `Leron.Audio.exe`.
*(Требуется .NET 8 Desktop Runtime).*
